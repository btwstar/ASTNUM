of ASTNUM that works 100% offline (all data in the WebView's localStorage via
`src/lib/local-api` — 55 endpoints mirroring the Next API routes).

## Prerequisites (what `scripts/toolchain-setup.sh` installs)

The toolchain lives INSIDE the project (survives environment resets — the
previous `~/jdk` + `~/android-sdk` were lost between sessions):

1. **Android SDK** at `android-app/toolchain/android-sdk` (cmdline-tools + `platforms;android-35` + `build-tools;35.0.0` + platform-tools).
2. **Full JDK 21** at `android-app/toolchain/jdk-21.0.12.1+1` (Temurin tarball via the Adoptium API — the system `java` is a JRE without `javac`; Capacitor 7 needs `sourceCompatibility 21`).
3. `android-app/android/local.properties` → `sdk.dir=<absolute path to the repo>/android-app/toolchain/android-sdk` (NOT committed — machine-specific).

Rebuild-from-scratch commands (if `android-app/toolchain/` is ever lost):

```bash
mkdir -p android-app/toolchain && cd android-app/toolchain
curl -sL -o jdk21.tar.gz "https://api.adoptium.net/v3/binary/latest/21/ga/linux/x64/jdk/hotspot/normal/eclipse" && tar xzf jdk21.tar.gz && rm jdk21.tar.gz
curl -sL -o cmdtools.zip "https://dl.google.com/android/repository/commandlinetools-linux-11076708_latest.zip" && unzip -q cmdtools.zip && mkdir -p android-sdk/cmdline-tools && mv cmdline-tools android-sdk/cmdline-tools/latest && rm cmdtools.zip
export JAVA_HOME=$PWD/jdk-21.0.12.1+1   # adjust to the extracted dir name
yes | android-sdk/cmdline-tools/latest/bin/sdkmanager --sdk_root=$PWD/android-sdk "platform-tools" "platforms;android-35" "build-tools;35.0.0"
echo "sdk.dir=$(pwd)/android-sdk" > ../android/local.properties
```

## Build (repeatable)

```bash
# 0) stop the dev server first (they share .next)
bash scripts/build-apk.sh        # export → out/ → android-app/www, api/ + public/download auto-restored

cd android-app
bun install                      # first time only
bun run cap sync android         # "bunx cap" fails to resolve the bin; use the package script
cd android
JAVA_HOME=../toolchain/jdk21 ./gradlew clean assembleDebug   # (toolchain dir is `jdk21` as installed by the setup script)
# → app/build/outputs/apk/debug/app-debug.apk
cp app/build/outputs/apk/debug/app-debug.apk ../../public/download/ASTNUM-v1.24-debug.apk
```

⚠️ **Always `gradlew clean` when web assets were REMOVED/renamed between builds.**
AGP's incremental packager updates the APK zip in place and a removed entry
(e.g. an old `download/*.apk` asset) leaves a multi-MB hole in the physical
file — same content, but the APK jumps from 6.5 MB to 12 MB. A clean build
repacks from scratch. (Verified: incremental 12.25 MB → clean 6.55 MB.)

Install on a phone: enable "Install unknown apps", copy/scan the APK, install.

## Release build (for Google Play — needs YOUR keystore)

```bash
keytool -genkeypair -v -keystore astnum-release.keystore -alias astnum \
  -keyalg RSA -keysize 2048 -validity 9125 -storetype PKCS12
cd android-app/android
JAVA_HOME=~/jdk ./gradlew bundleRelease   # → .aab for Play Console
```
See `docs/capacitor/ANDROID_BUILD.md` §signing + `docs/MANUAL_STEPS.md` for the
full Play checklist (target SDK verification, Data Safety, closed testing…).

## Known honest limits

- **Debug APK** = debug signing (fine for personal use/testing; Play needs the release flow above). v1.2 (versionCode 3) contains the master-grade muscle map + the 462/462-verified offline adapter.
- AI assistant returns an honest "requires the server" error inside the APK (no worker bundled) — quota UI still renders.
- Barcode scanning needs camera permission + Chromium WebView (manual entry always works).
- Data lives in localStorage (~5MB ceiling; body photos capped at 4MB with a friendly error). The native migration to `@capacitor-community/sqlite` is documented in ANDROID_BUILD.md.
- Tested in-browser (exact static payload) + manifest verified with apkanalyzer; **not** tested on a physical device.
